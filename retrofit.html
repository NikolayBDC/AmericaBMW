Popular projects

More features.
No hack-job feel.

The key to a good retrofit is not just installing a part, but correctly integrating it into the vehicle’s configuration.

I check the steering wheel, steering column module, wiring, and transmission compatibility. After installation I activate the function and test it in standard modes.

I select a compatible solution for the head unit and body, agree on component types, route the wiring, and code the display. Some systems may require calibration.

I check cluster and vehicle electronics compatibility, component origin, and required adaptation. History and identification data are never altered to hide mileage.

The project depends on body and equipment: sometimes only coding is needed, sometimes modules, wiring, control panels and installation are required. The full list is formed before ordering parts.
